১. ব্যাকএন্ড সিস্টেম আর্কিটেকচার ওভারভিউ (System Architecture Overview)
================================================================================
সিস্টেমটি Enterprise-Grade Modular Monolith আর্কিটেকচারে গঠিত, যা ভবিষ্যতে মাইক্রোসার্ভিসে 
রূপান্তরের উপযোগী।

মূল টেকনোলজি স্ট্যাক:
- Core Runtime: Node.js (v20+ LTS) + TypeScript
- Framework: Express.js (মডুলার রাউটার, কন্ট্রোলার ও সার্ভিস লেয়ার আর্কিটেকচার)
- Database & ODM: MongoDB Atlas + Mongoose (সর্বাধুনিক deprecation-free কনফিগারেশন)
- Data Validation: Zod Schema Validation (ইনকামিং রিকোয়েস্টে কঠোর ভ্যালিডেশন)
- Real-Time Communication: Socket.io (লাইভ চ্যাটজিপিটি নেগোসিয়েশন ও অর্ডার নোটিফিকেশন)
- AI Integration: OpenAI API (GPT-4o) + Computer Vision (ফটো কোয়ালিটি স্কোর ও ট্যাক্সোনমি)
- Storage: AWS S3 / Cloudinary (প্রোডাক্ট ইমেজ ও ভেন্ডর ডকুমেন্টস)
- Email Engine: Resend / Nodemailer (ক্লিন রেস্পন্সিভ HTML টেমপ্লেট সহ)

আর্কিটেকচারাল পলিসি:
১. Action-Oriented API Route Naming: সমস্ত এন্ডপয়েন্টে ডেসক্রিপটিভ অ্যাকশন পাথ (যেমন: /create-something, 
   /get-all-data, /view-details/:id) ব্যবহার বাধ্যতামূলক।
২. Mongoose Modernization: findOneAndUpdate() এ deprecated { new: true } সম্পূর্ণ নিষিদ্ধ; 
   সর্বদা { returnDocument: 'after' } ব্যবহার করতে হবে।
৩. Strict Data Validation: প্রতিটি রাউটে Zod স্কিমা দিয়ে ভ্যালিডেশন নিশ্চিত করা।
৪. Centralized Email Templates: কন্ট্রোলারে ইনলাইন HTML লেখা নিষিদ্ধ; সর্বদা src/shared/utils/emailTemplates.ts-এ 
   আলাদা ফাংশনে HTML সংরক্ষণ করতে হবে।

২. ডেটাবেস মডেল এবং স্কিমা ডিজাইন (Database Models & Schemas)

১) User Model (গ্রাহক, সেলার, প্রোভাইডার ও অ্যাডমিন)
---------------------------------------------------
Schema Fields:
- _id: ObjectId
- fullName: String (Required)
- email: String (Unique, Indexed, Lowercase)
- passwordHash: String (Bcrypt hashed)
- phone: String
- roles: Array of Strings ['customer', 'provider', 'seller', 'admin', 'superadmin']
- activeRole: String ('customer' | 'provider' | 'seller' | 'admin')
- avatar: String (URL)
- status: String ('Active' | 'Blocked' | 'Pending_Verification')
- providerDetails:
    * companyName: String
    * providerType: String ('Personal' | 'Company')
    * rating: Number (Default: 5.0)
    * reviewsCount: Number (Default: 0)
    * tradeLicense: String
    * verified: Boolean (Default: false)
- sellerDetails:
    * storeName: String
    * verifiedSeller: Boolean (Default: false)
    * rating: Number (Default: 5.0)
    * totalSales: Number (Default: 0)
- createdAt, updatedAt: Timestamps

২) MarketplaceProduct Model (ই-কমার্স ও এআই পণ্য)
------------------------------------------------
Schema Fields:
- _id: ObjectId
- name: String (Required, Indexed)
- category: String (Indexed)
- subcategory: String
- price: Number (Regular Listing Price)
- minNegotiablePrice: Number (গোপন ফ্লোর প্রাইস - শুধুমাত্র AI এর জন্য, বায়ারদের কাছে গোপন)
- condition: String ('Brand New' | 'Like New' | 'Refurbished' | 'Good')
- color: String (AI Detected)
- tags: Array of Strings (Indexed)
- image: String (Primary High-Res Image URL)
- galleryImages: Array of Strings
- description: String
- sellerId: ObjectId (Ref: 'User', Indexed)
- sellerName: String
- status: String ('Available' | 'Sold' | 'UnderReview')
- complianceApproved: Boolean (Default: true)
- aiInspection:
    * detectedType: String
    * detectedCategory: String
    * detectedColor: String
    * qualityScore: Number (0 - 100)
    * angleAdvice: String
    * lightingStatus: String ('Optimal' | 'Suboptimal' | 'Too Dim')
    * suggestedTags: Array of Strings
- chatGptRules:
    * lowestAcceptablePrice: Number
    * shippingTerms: String
    * returnPolicy: String
    * customFaq: String
    * allowNegotiation: Boolean (Default: true)
- createdAt, updatedAt: Timestamps

৩) ServiceBooking Model (অন-ডিমান্ড সার্ভিস বুকিং)
------------------------------------------------
Schema Fields:
- _id: ObjectId
- bookingCode: String (Unique, e.g. 'BK-9012')
- customerId: ObjectId (Ref: 'User', Indexed)
- providerId: ObjectId (Ref: 'User', Indexed)
- serviceTitle: String
- category: String
- bookingDate: Date
- timeSlot: String
- amount: Number
- address: String
- customerNotes: String
- status: String ('Pending' | 'Confirmed' | 'Completed' | 'Cancelled')
- paymentStatus: String ('Unpaid' | 'Escrow_Held' | 'Released_To_Provider' | 'Refunded')
- createdAt, updatedAt: Timestamps

৪) ChatGptNegotiationLog Model (এআই অডিট ও নিরাপত্তা লগ)
------------------------------------------------------
Schema Fields:
- _id: ObjectId
- sessionId: String (Indexed)
- productId: ObjectId (Ref: 'MarketplaceProduct', Indexed)
- productName: String
- buyerId: ObjectId (Ref: 'User', Optional)
- sellerId: ObjectId (Ref: 'User')
- originalPrice: Number
- offeredPrice: Number
- finalNegotiatedPrice: Number (Null if rejected)
- status: String ('Accepted' | 'Rejected' | 'In_Progress')
- conversationSnippet: String
- clientIp: String
- createdAt: Timestamp

৫) PlatformSettings Model (গ্লোবাল সেটিংস ও সিএমএস)
--------------------------------------------------
Schema Fields:
- platformName: String
- primaryColor: String (Hex code, e.g. '#0EA5E9')
- logoUrl: String
- maxPlatformDiscountPercent: Number (Default: 25)
- allowAiNegotiationsGlobally: Boolean (Default: true)

- aiTaxonomyCategories: Array of Strings

    * terms_EN: String, terms_DE: String
    * faq_EN: String, faq_DE: String

[১] Deprecation-Free Mongoose Update Standard:
---------------------------------------------
// { new: true } সম্পূর্ণ নিষিদ্ধ; সর্বদা { returnDocument: 'after' } ব্যবহার্য
export const updateProductListingStatus = async (productId: string, newStatus: string) => {
  const updatedProduct = await MarketplaceProduct.findByIdAndUpdate(
    productId,
    { status: newStatus },
    { returnDocument: 'after', runValidators: true }
  ).lean();

  if (!updatedProduct) {
    throw new AppError("Product not found with specified ID", "NOT_FOUND", 404);
  }
  return updatedProduct;
};
